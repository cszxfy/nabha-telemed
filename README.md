# Nabha Telemed

Telemedicine platform for rural healthcare access — React PWA frontend,
Node.js/Express backend, and a Python microservice for symptom triage.

## Structure
- `frontend/` — React PWA (patient + doctor portals)
- `backend/` — Node.js/Express API
- `ml-model/` — Python symptom triage service
- `docs/` — architecture, API contract, DB schema, NDHM alignment
